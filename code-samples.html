01 / DYNAMIC CONTENT

Preserve a manually selected content order

When editors choose the display order in an ACF Relationship field attached to a taxonomy term, use the selected IDs as the query order. The taxonomy filter remains in place so only posts belonging to the current term are returned.

PHPWordPressACF RelationshipWP_Query
<?php
$taxonomy = 'course-category';
$term     = get_queried_object();

if ($term instanceof WP_Term && $term->taxonomy === $taxonomy) {
    // ACF field attached to this taxonomy term.
    $selected_courses = get_field(
        'ordered_courses',
        $taxonomy . '_' . $term->term_id
    );

    $ordered_ids = array();

    if (is_array($selected_courses)) {
        foreach ($selected_courses as $course) {
            $id = $course instanceof WP_Post
                ? (int) $course->ID
                : absint($course);

            if ($id > 0) {
                $ordered_ids[] = $id;
            }
        }
    }

    $ordered_ids = array_values(array_unique($ordered_ids));

    if ($ordered_ids) {
        $query = new WP_Query(array(
            'post_type'      => 'course-card',
            'post_status'    => 'publish',
            'posts_per_page' => -1,
            'post__in'       => $ordered_ids,
            'orderby'        => 'post__in',
            'tax_query'      => array(
                array(
                    'taxonomy' => $taxonomy,
                    'field'    => 'term_id',
                    'terms'    => $term->term_id,
                ),
            ),
        ));

        // Render the cards from $query, then call
        // wp_reset_postdata() after the loop.
    }
}

02 / FRONT-END INTERACTION

Initialize a carousel only when useful

A reusable carousel should avoid duplicate initialization, wait for its dependency to be available, and use a simple static layout when there are too few items to scroll.

JavaScriptSwiperResponsive UI
document.addEventListener('DOMContentLoaded', () => {
  document.querySelectorAll('.profile-carousel').forEach((element) => {
    if (element.dataset.initialized === 'true') return;

    const slides = element.querySelectorAll('.swiper-slide');
    const columns = Math.max(
      1,
      Number.parseInt(element.dataset.columns || '3', 10)
    );

    // A static grid is simpler when scrolling is unnecessary.
    if (slides.length <= columns) {
      element.classList.add('is-static');
      element.style.setProperty('--columns', columns);
      return;
    }

    // This example assumes Swiper has already been loaded.
    if (typeof Swiper === 'undefined') return;

    element.dataset.initialized = 'true';

    new Swiper(element, {
      slidesPerView: columns,
      spaceBetween: 20,
      breakpoints: {
        320: { slidesPerView: Math.min(2, columns) },
        1024: { slidesPerView: columns }
      }
    });
  });
});

03 / REUSABLE COMPONENT

Create a configurable information banner shortcode

A shortcode can expose a small number of presentation options while escaping attribute output and allowing only permitted markup in the content. Keep component styles scoped to the component class.

PHPShortcodesHTMLCSS
<?php
function portfolio_info_banner_shortcode($atts, $content = null) {
    $atts = shortcode_atts(
        array('icon' => ''),
        $atts,
        'portfolio_info_banner'
    );

    ob_start();
    ?>
    <aside class="portfolio-info-banner">
        <?php if (!empty($atts['icon'])) : ?>
            <img
                class="portfolio-info-banner__icon"
                src="<?php echo esc_url($atts['icon']); ?>"
                alt=""
                aria-hidden="true"
            >
        <?php endif; ?>

        <div class="portfolio-info-banner__content">
            <?php echo wp_kses_post($content); ?>
        </div>
    </aside>
    <?php
    return ob_get_clean();
}
add_shortcode(
    'portfolio_info_banner',
    'portfolio_info_banner_shortcode'
);
